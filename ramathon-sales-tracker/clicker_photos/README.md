# Clicker photos

One photo per clicker design. Name each file exactly as listed so the tracker can find it.
Any of `.jpg`, `.jpeg`, `.png`, or `.webp` works. Phone photos work as-is, but each one is often 3 to 5 MB,
which slows the first load on carnival wifi; shrink them (or ask Claude to) after uploading.
iPhone: upload from Safari or the GitHub app so photos arrive as JPG, not HEIC (browsers can't show HEIC).
Until a design has a photo, its button shows the design's first letter.

## How to upload (GitHub website, works from a phone)

1. Open the live folder on GitHub: branch `presentations`, folder `ramathon-sales-tracker/clicker_photos/`.
2. **Add file > Upload files**, drag the photos in, then **Commit changes**.
