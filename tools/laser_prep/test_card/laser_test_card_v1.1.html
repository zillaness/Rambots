Step 0: import into UCP (no printing)

The README in this folder has the full checklist and the tables to fill in. Short version:

  1. In UCP, open the System tab and look for Direct Import Package. Note whether it is there and on. Ask a mentor before turning on any trial.
  2. Click Save PDF and import the PDF. Check red cuts, blue scores, black rasters, and the size.
  3. Import the DXFs: colored, colored_r12, raw_mm, curves, color_codes. ULS says DXF import is vectors only, so black fills in a DXF are not expected to engrave. Judge raster on the PDF.
  4. On the raw DXF: did UCP ask for units, and is the square 4.000 in? Can you change a line's color inside UCP?
  5. Screenshot every import dialog.

Step 1: print to the ULS driver

Run these in order and write down the printer resolution (DPI) the ULS driver is set to each time. Lines thinner than one printer pixel print as one pixel.

  1. Adobe Reader (if installed): open the saved PDF, Print, pick the ULS printer. Page Sizing: Actual size, checked every time, because Reader remembers the last setting. Print in grayscale off, Print as image off. The preview shows the art in the top-left corner.
  2. Saved PDF in Chrome or Edge: open the saved PDF in the browser and print it to the ULS printer. If a Print as image box shows, leave it off.
  3. Chrome or Edge page print: click Print (Chrome test). Destination: the ULS printer. Paper size: the bed size above. Margins: None. Scale: Default (100). Headers and footers: off. Color, not black and white.

If the ULS power and speed window can only be reached from the Windows print dialog, write that down. It changes the design.

Measure

Kerf makes the dropped-out piece small and the hole in the sheet big by the same amount, so average them. Measure X and Y with calipers.

size = (piece + hole) / 2   Pass if 4.000 ± 0.010 in on both axes.   kerf = (hole − piece) / 2
