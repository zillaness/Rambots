# Prize photos

One photo per prize. Upload them here with any names, then send the list of prizes and their card prices; the tracker's `PRIZES` list gets updated to match (one button per prize, so Totals can show which prizes did best).

Until then the Prize Table shows three placeholder buttons: Small prize (3 cards), Medium prize (6), Grand prize (9).

## How to upload (GitHub website, works from a phone)

1. Open this folder on GitHub (branch `presentations`, folder `ramathon-sales-tracker/prize_photos/`).
2. **Add file > Upload files**, drag the photos in, then **Commit changes**.

JPG or PNG; iPhone photos should come through as JPG when uploaded from Safari or the GitHub app.
