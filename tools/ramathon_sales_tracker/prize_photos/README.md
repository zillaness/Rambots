# Prize photos

One photo per prize. Upload them here with any names, then send the list of prizes and their levels; the tracker's `PRIZES` list gets updated to match (one button per prize, so Totals can show which prizes did best).

Levels: small 1 card, medium 3, grand 9.

| Prize | Level | File name |
|---|---|---|
| Toy car | small (1) | `toy_car.jpg` |
| Pen | small (1) | `pen.jpg` |
| Cheese squish | medium (3) | `cheese_squish.jpg` |
| Mini plush | medium (3), best guess | `mini_plush.jpg` |
| Dino plush | grand (9) | `dino_plush.jpg` |
| Capsule toy | small (1), best guess | `capsule_toy.jpg` |

The **Other small / medium / grand prize** buttons (1 / 3 / 9 cards) cover any prize without its own button.

## How to upload (GitHub website, works from a phone)

1. Open this folder on GitHub (branch `presentations`, folder `ramathon-sales-tracker/prize_photos/`).
2. **Add file > Upload files**, drag the photos in, then **Commit changes**.

JPG or PNG; iPhone photos should come through as JPG when uploaded from Safari or the GitHub app.
