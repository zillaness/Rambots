# Clicker photos

One photo per clicker design. Name each file exactly as listed so the tracker can find it.
Any of `.jpg`, `.jpeg`, `.png`, or `.webp` is fine; phone photos are fine too (they get shrunk before going live).

## How to upload (GitHub website, works from a phone)

1. Open this folder on GitHub (branch `claude/focused-dirac-gom1ys`).
2. **Add file > Upload files**, drag the photos in, then **Commit changes**.
