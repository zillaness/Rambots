# TypeSpecimen

A type specimen showing the Rambots scale in Helvetica Neue. Each row labels a
step (Display → Caption) and renders the sample at that size and weight — the
typography reference for the style guide.

```tsx
import { TypeSpecimen } from '@rambots/design-system';

<TypeSpecimen />
<TypeSpecimen sample="Go Rambots!" />
```
