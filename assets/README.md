# Rambots Brand Assets

Drop brand/logo source files here. Expected files (used by the design system build):

## logos/
- `robo-ram.svg` / `robo-ram.png` — Robo Ram, the **gearhead** main logo
- `robo-ram-pfp.png` — Robo Ram profile-picture variant
- `graffiti.svg` / `graffiti.png` — the **graffiti / streetwear** wordmark
  (formerly the "stussy" logo — trademark reference removed)

## Naming
- Always **Rambots** or **RAMBOTS** — never "RamBots" or "Ram Bots".

## Brand quick reference
- Rambot Red `#A31F36` — primary background / school color
- Rambot Yellow `#F4A81C` — text / logo accent
- Font: Helvetica Neue

## fonts/
Helvetica Neue is proprietary and cannot be embedded from scratch. Drop licensed
webfont files here to wire them into the design system:
- `HelveticaNeue-Roman.woff2` (400)
- `HelveticaNeue-Medium.woff2` (500)
- `HelveticaNeue-Bold.woff2` (700)
Until then the system falls back to: "Helvetica Neue", Helvetica, Arial, sans-serif.
